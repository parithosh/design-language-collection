Chapter one

Fabrics

Each fabric is six seed colours; every other token follows from them, so each one feels like the same cloth in a different dye. Pick one to dress this whole page in it.

Chapter two

The Loom

The customizer from piecesoflife's Admin → Appearance. Start from a fabric, then change three colours. Everything else (hover shades, text on colour, borders, the emblem's threads) follows, and the loom quietly fixes any colour that would be hard to read.
