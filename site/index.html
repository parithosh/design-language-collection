Design languages

The colours, type and rules I use across my projects.

Two themes live here. Each one is a set of tokens, a short set of rules, and generated stylesheets, Tailwind themes, and editor and terminal themes. They share the same token names, so any project can switch between them by swapping one stylesheet.
